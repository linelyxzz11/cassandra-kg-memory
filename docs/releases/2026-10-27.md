responses are excluded.

## Interpretation and population boundaries

- Retrieval: 1,536 valid-gold questions comprise 390 development and 1,146 held-out
  questions. Aggregate and held-out results are not interchangeable.
- Reader: 1,986 questions per prompt setting; the 1,487-question subset excludes
  development scopes and is an additional aggregation, not a replacement main set.
- LightMem's source projection and native-fact Reader contexts differ from raw-turn
  evidence. Preserve that granularity/budget distinction when comparing scores.
- E0 distinguishes arrival/queueing, client-observed raw-write calls and checked
  retrieval readiness. These are not database commit latency or matched durability.
- E3 supports the tested single-process, single-owner coordination mechanism. It
  does not establish distributed fencing, multi-index atomic publication or zero
  failures under arbitrary schedules. Pre-ready stale observations are distinct
  from post-final-ready target failures.
- Some historical snapshots have absolute paths and external dependencies. They
  are audit sources, not drop-in portable experiment commands.

## Verification and exclusions

[`MANIFEST.json`](../../results/release_20261027/MANIFEST.json) lists the original
workspace-relative source, destination, byte count and SHA-256 for every copied
source or result artifact. Result bytes are not reformatted or recomputed in this
release. The active backend cleanup and serialized update service are accompanied
by database-free regression tests in `experiments/consistency/`.

Not included: complete run traces, API caches/requests/responses, credentials,
unreviewed handoff drafts, manuscript TeX/PDF/PPTX, large embeddings or ranking dumps,
virtual environments, database volumes and delivery ZIPs. Inputs already tracked
by earlier releases are left unchanged. Historical reports outside this release
remain valid only within their recorded protocols; the release is not an assertion
that every old or locally generated file is publication-ready.
