# Old Sample-Scoped Result Sources

## Dataset
- locomo10.json -> memory_records.csv (5882 memories, 10 conversations)
- locomo_qa_records.csv (1986 QA, cat1-5)
- locomo_evidence_map.csv (qa_id -> memory_id truth labels)
- cat5 excluded, cat1-4 used: 1540 queries

## BGE Embeddings
- Generated by scripts/memory/encode_bge_large_api.py
- Model: BAAI/bge-large-en-v1.5, dim=1024
- API key was user-provided, NOT embedded in code
- Cached as .npy files: results/locomo_memory_bge_large.npy, results/locomo_qa_bge_large.npy
- All retrieval scripts load these .npy files, do NOT call API directly

## Retrieval Results
- sample_scoped_retrieval_summary.csv: aggregate R@1/R@5/R@10/MRR by method
- analysis_category_wise.csv: per-category breakdown for 4 methods
- Generated by scripts/memory/locomo_retrieval_sample_scoped.py
- This script reads pre-computed retrieval CSVs (locomo_dense_bge_results.csv, etc.)
- Filters to sample-scoped (only within same conversation), re-evaluates hits

## Per-query Retrieval CSVs
- locomo_bm25_results.csv: BM25 global top10 per query
- locomo_dense_bge_results.csv: Dense-bge global top10 per query
- locomo_cassandra_kg_results.csv: TF-IDF+KG boost top10
- locomo_neo4j_results.csv: same as cassandra
- All have columns: qa_id, category, gold_memory_ids, retrieved_memory_ids, hit1, hit5, hit10, rr

## Key Note
The pre-computed CSVs store GLOBAL retrieval results. The sample-scoped script filters to same-sample only.
My hybrid script should either:
  (a) Read from these pre-computed CSVs and filter, OR
  (b) Recompute Dense ranking from .npy embeddings within sample scope

Option (a) preserves the exact ranking from the original script.
Option (b) may have small differences due to floating point in cosine similarity dot product.

## Root Cause of Discrepancy (TENTATIVE)
The hybrid script's Dense ranking differs from sample_scoped_retrieval_summary.csv because:
1. Dense-bge_results.csv: pre-computed from global pool, then sample-scope filtered
2. My hybrid script: computed from scratch using .npy embeddings within sample-scope
3. The ranking order may differ slightly, especially at top positions
4. BM25: global results filtered to sample-scope => loses true ranking order entirely
